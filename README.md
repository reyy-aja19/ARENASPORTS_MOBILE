## Local Demo Mode

The app currently runs without a Laravel backend. Demo accounts, fields, bookings, schedules, matches, chat messages, rewards, points, notifications, and venue requests are stored on the device with `SharedPreferences`.

Local demo data is not synchronized between devices. Booking and reward redemption are simulations; no real payment is processed.
